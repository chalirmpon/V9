# คลังยาอัจฉริยะ V9 — หน้าเปิดระบบจาก GitHub Pages

เปิดระบบคลังยาอัจฉริยะ V9 ของหน่วยงานจากลิงก์นี้ แทนลิงก์ script.google.com

- ไม่มีแถบ "แอปพลิเคชันนี้สร้างโดยผู้ใช้ Google Apps Script"
- สแกนบาร์โค้ด / QR ด้วยกล้องสดได้
- ติดตั้งเป็นแอปบนมือถือและคอมพิวเตอร์ได้ (เปิดเต็มจอ ไม่มีแถบที่อยู่)

**วิธีใช้:** เปิด `https://chalirmpon.github.io/V9/?api=` ตามด้วยลิงก์ Web app (`…/exec`) ของหน่วยงาน
ครั้งต่อไปเปิด `https://chalirmpon.github.io/V9/` ได้เลย เครื่องจะจำลิงก์ไว้

**ต้องมีในโปรเจกต์ Apps Script ของหน่วยงาน:** ไฟล์สคริปต์ `WebGitHub.gs` แล้ว Deploy › Manage deployments › แก้ไข › New version
และ Web app ตั้ง "ผู้มีสิทธิ์เข้าถึง: ทุกคน"

หน้านี้ไม่มีข้อมูลยา ผู้ใช้ หรือลิงก์ของหน่วยงานใด — หน้าเว็บ V9 โหลดสดจากระบบของแต่ละหน่วยงาน ออกรุ่นใหม่ไม่ต้องแก้ไฟล์ในนี้

**ติดตั้งเป็นแอป:** Android — Chrome › ⋮ › ติดตั้งแอป • iPhone — Safari › แชร์ › เพิ่มไปยังหน้าจอโฮม • คอมพิวเตอร์ — Chrome / Edge › ไอคอนติดตั้งในแถบที่อยู่

พัฒนาโดย นายเฉลิมพล ศรีนวลแสง นวก.สธ.ชพ.
