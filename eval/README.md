# ระบบประเมินผลการปฏิบัติงาน — หน้าเปิดระบบจาก GitHub Pages

เปิดระบบประเมินผลการปฏิบัติงานของหน่วยงานจากลิงก์นี้ แทนลิงก์ script.google.com

- ไม่มีแถบสีเทา "แอปพลิเคชันนี้สร้างโดยผู้ใช้ Google Apps Script" — ได้พื้นที่ทำงานบนมือถือเพิ่มขึ้น
- ติดตั้งเป็นแอปบนมือถือและคอมพิวเตอร์ได้ (เปิดเต็มจอ ไม่มีแถบที่อยู่)

**วิธีใช้:** เปิด `https://chalirmpon.github.io/V9/eval/?api=` ตามด้วยลิงก์ Web app (`…/exec`) ของหน่วยงาน
ครั้งต่อไปเปิด `https://chalirmpon.github.io/V9/eval/` ได้เลย เครื่องจะจำลิงก์ไว้

**ต้องมีในโปรเจกต์ Apps Script ของหน่วยงาน:** ไฟล์สคริปต์ `WebGitHub.gs` (อยู่ถัดจากไฟล์ รหัส) แล้ว การทำให้ใช้งานได้ › จัดการ › แก้ไข › เวอร์ชันใหม่
และ Web app ตั้ง "ผู้มีสิทธิ์เข้าถึง: ทุกคน" (ระบบมีหน้าเข้าสู่ระบบของตัวเอง)

หน้านี้ไม่มีข้อมูลบุคลากร ผลการประเมิน หรือลิงก์ของหน่วยงานใด — หน้าเว็บโหลดสดจากระบบของแต่ละหน่วยงาน ออกรุ่นใหม่ไม่ต้องแก้ไฟล์ในนี้

**ติดตั้งเป็นแอป:** Android — Chrome › ⋮ › ติดตั้งแอป • iPhone — Safari › แชร์ › เพิ่มไปยังหน้าจอโฮม • คอมพิวเตอร์ — Chrome / Edge › ไอคอนติดตั้งในแถบที่อยู่

พัฒนาโดย นายเฉลิมพล ศรีนวลแสง นวก.สธ.ชพ.
